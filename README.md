# Retro Animation Website

A nostalgic early 2000s style website featuring classic web animations and design elements.

## Features

- Matrix-style falling numbers animation
- Retro download progress bars
- Animated guestbook entries
- Rainbow text effects
- Cursor trails
- Star field background
- Visitor counter
- Classic "Under Construction" banner

## Technologies Used

- HTML5
- CSS3 (with animations)
- Vanilla JavaScript

## How to Run

Simply open `index.html` in a web browser to view the site.

## Preview

The site features a classic early 2000s web design with:
- Comic Sans MS font
- Neon colors
- Animated elements
- Retro-style buttons
- Marquee text
